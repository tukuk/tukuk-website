Ciri projek

Projek ini sesuai untuk portfolio, demo AI, laman peribadi, atau asas web app yang lebih besar. Tiada database diperlukan untuk versi percuma ini.

Multimedia

Bantu hasilkan idea music, konsep video, prompt gambar, storyboard, lirik, dan skrip pendek.

Belajar dan menulis

Terangkan topik, buat nota, ringkaskan idea, tulis artikel, caption, email, dan dokumen.

Melukis, projek, coding

Bantu lukis konsep, susun projek, tulis kod, debug, buat roadmap, dan deploy web app.

Pelankan projek

Gunakan pelan ini untuk kembangkan projek dari demo statik kepada web AI sebenar.

Roadmap ringkas

  • 1. Tambah halaman baharu seperti portfolio, dokumentasi, dan galeri demo.
  • 2. Sambung API AI melalui Cloudflare Worker atau backend kecil supaya API key tidak terdedah.
  • 3. Simpan sejarah chat dalam localStorage untuk pengalaman lebih baik.
  • 4. Tambah tema terang/gelap, carian, dan halaman admin ringkas.
